Question 1 — Energy/Power Signals & Periodicity Condition

Part (a) — Energy and Power Signals

Signals are classified based on their total energy and average power:

Total Energy: E = ∫₋∞^∞ |x(t)|² dt Average Power: P = lim[T→∞] (1/2T) ∫₋T^T |x(t)|² dt

Energy Signal: A signal where E < ∞ and therefore P = 0.

Power Signal: A signal where 0 < P < ∞ and therefore E → ∞.

PropertyEnergy SignalPower Signal
Total Energy EFinite (E < ∞)Infinite
Average Power PP = 0Finite (0 < P < ∞)
Examplesx(t) = e−|t|, rect pulsecos(ω₀t), periodic signals

Part (b) — Condition for ejωn to be Periodic

A discrete-time signal x[n] is periodic with period N if x[n+N] = x[n] for all n and some positive integer N.

For e^{jωn} to be periodic with period N: e^{jω(n+N)} = e^{jωn} for all n ⟹ e^{jωN} = 1 ⟹ ωN = 2πm, for some integer m ⟹ ω/2π = m/N (a rational number)
Conclusion: ejωn is periodic ⟺ ω/2π is rational (ω = 2πm/N for integers m, N). If ω/2π is irrational, the signal is aperiodic.

Part (b) — Parseval's Relation for DT Periodic Signals

Statement: For x[n] periodic with period N having DTFS coefficients {c_k}:

(1/N) Σ_{n=0}^{N−1} |x[n]|² = Σ_{k=0}^{N−1} |c_k|² Average Power = Sum of squared magnitudes of DTFS coefficients

Proof:

LHS = (1/N) Σ_n x[n]·x*[n] Substitute x*[n] = Σ_k c_k* e^{−j2πkn/N} (conjugate of synthesis equation): = (1/N) Σ_n x[n] · Σ_k c_k* e^{−j2πkn/N} = Σ_k c_k* · [ (1/N) Σ_n x[n] e^{−j2πkn/N} ] By definition, the bracketed term is c_k (DTFS analysis equation): = Σ_k c_k* · c_k = Σ_k |c_k|² = RHS ∎

Question 3 — Complex Conjugation Property of CT Fourier Transform

Statement: If x(t) ↔ X(jω), then x*(t) ↔ X*(−jω).

Proof:

By definition: X(jω) = ∫₋∞^∞ x(t) e^{−jωt} dt Take conjugate of both sides: X*(jω) = ∫₋∞^∞ x*(t) e^{+jωt} dt Replace ω with −ω: X*(−jω) = ∫₋∞^∞ x*(t) e^{−jωt} dt = FT{x*(t)} Therefore: x*(t) ↔ X*(−jω) ∎

Conjugate Symmetry for Real Signals

If x(t) is purely real: x*(t) = x(t), so applying the property:

x*(t) = x(t) ⟹ FT{x*(t)} = FT{x(t)} = X(jω) But from the property: FT{x*(t)} = X*(−jω) Therefore: X*(−jω) = X(jω) ← Conjugate Symmetry This implies: |X(−jω)| = |X(jω)| (Magnitude is even) ∠X(−jω) = −∠X(jω) (Phase is odd) Re{X(jω)} is even, Im{X(jω)} is odd
Conclusion: The Fourier Transform of a real CT signal is always conjugate symmetric.

Question 4 — DTFT and 4-point DFT

Part (a) — DTFT of x[n] = aⁿu[n], 0 < a < 1

X(e^{jω}) = Σ_{n=−∞}^{∞} x[n] e^{−jωn} = Σ_{n=0}^{∞} aⁿ e^{−jωn} = Σ_{n=0}^{∞} (a e^{−jω})ⁿ This is a geometric series with ratio r = ae^{−jω}. Since |a| < 1, |r| < 1, it converges: X(e^{jω}) = 1 / (1 − a e^{−jω})
Magnitude: |X(e^{jω})| = 1 / √(1 + a² − 2a·cos(ω)) Phase: ∠X(e^{jω}) = −arctan[a·sin(ω) / (1 − a·cos(ω))]
Result: X(ejω) = 1/(1 − ae−jω)

Part (b) — 4-point DFT of x[n] = {3, −2, 1} (zero-padded)

Pad to length 4: x[n] = {3, −2, 1, 0} for n = 0, 1, 2, 3.

X[k] = Σ_{n=0}^{3} x[n] W_4^{nk}, where W_4 = e^{−j2π/4} = e^{−jπ/2} = −j Powers: W_4^0 = 1, W_4^1 = −j, W_4^2 = −1, W_4^3 = j X[0] = 3(1) + (−2)(1) + 1(1) + 0(1) = 3 − 2 + 1 = 2 X[1] = 3(1) + (−2)(−j) + 1(−1) + 0(j) = 3 + 2j − 1 = 2 + 2j X[2] = 3(1) + (−2)(−1) + 1(1) + 0(−1) = 3 + 2 + 1 = 6 X[3] = 3(1) + (−2)(j) + 1(−1) + 0(−j) = 3 − 2j − 1 = 2 − 2j

Question 5 — Nyquist Sampling Theorem

Statement: A band-limited signal with highest frequency fm can be perfectly reconstructed from its samples if the sampling rate fs satisfies:

f_s ≥ 2f_m (Nyquist Rate = 2f_m)

Finding Nyquist Rate for x(t) = (1/2π) cos(50πt) cos(500πt)

Apply the product-to-sum identity: cos A·cos B = ½[cos(A−B) + cos(A+B)]

x(t) = (1/2π) · cos(50πt)·cos(500πt) = (1/4π) · [cos(500πt − 50πt) + cos(500πt + 50πt)] = (1/4π) · [cos(450πt) + cos(550πt)] Frequency components: f₁ = 450π / (2π) = 225 Hz f₂ = 550π / (2π) = 275 Hz Maximum frequency: f_m = 275 Hz
Nyquist Rate = 2 × fm = 2 × 275 = 550 Hz (550 samples/second minimum)

Question 6 — LTI System Output & Ideal LPF

Part (a) — LTI System Output

LTI System: A Linear Time-Invariant system is completely characterized by its impulse response h(t). The output is the convolution: y(t) = x(t) ∗ h(t).

h(t) = e^{−2t} u(t) x(t) = { 1, |t| < 5 { 0, otherwise y(t) = ∫₋∞^∞ x(τ) h(t−τ) dτ = ∫₋₅^{5} e^{−2(t−τ)} u(t−τ) dτ

Case 1 — t < −5: No overlap ⟹ y(t) = 0

Case 2 — −5 ≤ t < 5: y(t) = ∫₋₅^t e^{−2(t−τ)} dτ = e^{−2t} [e^{2τ}/2]_{−5}^{t} = (1 − e^{−2(t+5)}) / 2 Case 3 — t ≥ 5: y(t) = ∫₋₅^5 e^{−2(t−τ)} dτ = e^{−2t} [e^{2τ}/2]_{−5}^{5} = (e^{−2(t−5)} − e^{−2(t+5)}) / 2

Part (b) — Ideal LPF is Not Practically Realizable

The ideal LPF has frequency response: H(jω) = 1 for |ω| ≤ ωc, 0 otherwise.

Its impulse response (inverse FT) is:

h(t) = ω_c/π · sinc(ω_c t / π) = sin(ω_c t) / (πt) (for all t)

Reasons for non-realizability:

  • Non-causality: h(t) ≠ 0 for t < 0 — output depends on future input
  • Infinite duration: h(t) is non-zero for all time, cannot be stored or implemented
  • Physical impossibility: Cannot build a system that responds before excitation
Paley-Wiener Condition: For h(t) to be causal, ∫₋∞^∞ |ln|H(jω)|| / (1+ω²) dω < ∞. The ideal LPF has H(jω) = 0 over a range of ω, making this integral diverge → not realizable.

Question 8 — LCCDE: Transfer Function & Impulse Response

Given: y[n] = 0.4·y[n−1] + x[n]

Transfer Function H(z)

Take Z-transform (using time-shift property z⁻¹): Y(z) = 0.4·z⁻¹·Y(z) + X(z) Y(z)(1 − 0.4z⁻¹) = X(z) H(z) = Y(z)/X(z) = 1/(1 − 0.4z⁻¹) = z/(z − 0.4) Pole: z = 0.4 (inside unit circle → stable) Zero: z = 0

Impulse Response h[n]

H(z) = z/(z − 0.4) is a first-order all-pole filter. Inverse Z-transform (using standard pairs): H(z) = 1/(1 − 0.4z⁻¹) ↔ h[n] = (0.4)ⁿ u[n] The system is causal and stable (|pole| = 0.4 < 1).
h[n] = (0.4)n u[n] — decaying geometric sequence for n ≥ 0

Impulse response h[n] = (0.4)nu[n]

H(e^{jω}) = H(z)|_{z=e^{jω}} = 1/(1 − 0.4e^{−jω}) |H(e^{jω})| = 1/√(1 + 0.16 − 0.8cos(ω)) This is a low-pass filter (gain is maximum at ω=0, rolls off toward ω=π).
