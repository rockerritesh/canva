Q2 — Fourier Series Coefficient (Exponential Form) + Dirichlet Conditions
Exponential Fourier Series
For a periodic signal x(t) with period T₀: x(t) = Σ_{k=−∞}^{∞} Cₖ · e^(jkω₀t) where ω₀ = 2π/T₀ Multiply both sides by e^(−jnω₀t) and integrate over one period: ∫₀^{T₀} x(t)·e^(−jnω₀t) dt = Σ_k Cₖ ∫₀^{T₀} e^(j(k−n)ω₀t) dt Orthogonality of complex exponentials: ∫₀^{T₀} e^(j(k−n)ω₀t) dt = { T₀, k = n { 0, k ≠ n Therefore: ┌─────────────────────────────────────────────────────┐ │ Cₖ = (1/T₀) ∫₀^{T₀} x(t) · e^(−jkω₀t) dt │ └─────────────────────────────────────────────────────┘ Physical meaning: Cₖ is the complex amplitude of the k-th harmonic
Dirichlet Conditions (for FS to exist)
  • x(t) must be absolutely integrable over one period: ∫₀^{T₀}|x(t)|dt < ∞
  • x(t) must have a finite number of maxima and minima in one period
  • x(t) must have a finite number of discontinuities in one period
  • At discontinuities, FS converges to the average of left and right limits
⚠️ Example satisfying Dirichlet: Square wave x(t) (periodic, piecewise constant)
Example violating: x(t) = sin(1/t) near t=0 — infinite oscillations in one period

Q5 — Sampling Theorem + Nyquist Rate for x(t) = 1 + cos(2000πt) + sin(4000πt)
Sampling Theorem (Nyquist-Shannon)

A continuous-time, band-limited signal with maximum frequency fmax can be perfectly reconstructed from its uniform samples if the sampling frequency satisfies:

fs ≥ 2·fmax (Nyquist Criterion) Minimum fs = 2·fmax is the Nyquist Rate
Analysis of Given Signal
x(t) = 1 + cos(2000πt) + sin(4000πt) Component 1: DC (1) → f₁ = 0 Hz Component 2: cos(2000πt) → 2πf = 2000π → f₂ = 1000 Hz Component 3: sin(4000πt) → 2πf = 4000π → f₃ = 2000 Hz Maximum frequency: fmax = 2000 Hz ╔══════════════════════════════════════╗ ║ Nyquist Rate = 2 × 2000 = 4000 Hz ║ ║ Sampling interval Ts = 1/4000 s ║ ╚══════════════════════════════════════╝

Q6 — System Properties + Time-Variance Check: y(t) = sin[x(t)]
System Properties (Overview)
  • Linearity — Superposition: f(ax₁+bx₂) = af(x₁)+bf(x₂)
  • Time-Invariance — Shift in input causes equal shift in output
  • Causality — Output depends only on present/past inputs
  • Memory — Output depends on past/future inputs
  • Stability — Bounded input → Bounded output (BIBO)
  • Invertibility — Unique input for each output
Check Time-Invariance for y(t) = sin[x(t)]
Step 1: Delay the INPUT by t₀, then apply system: x₁(t) = x(t − t₀) y₁(t) = sin[x₁(t)] = sin[x(t − t₀)] Step 2: Apply system first, then delay OUTPUT: y(t) = sin[x(t)] y(t − t₀) = sin[x(t − t₀)] Comparison: y₁(t) = y(t − t₀)? sin[x(t−t₀)] = sin[x(t−t₀)] ✓ EQUAL!
✅ y(t) = sin[x(t)] is TIME-INVARIANT
Check Linearity
Let x(t) = ax₁(t) + bx₂(t): y(t) = sin[ax₁(t) + bx₂(t)] ≠ a·sin[x₁(t)] + b·sin[x₂(t)] ✗ (sin is nonlinear)
❌ y(t) = sin[x(t)] is NON-LINEAR
📌 System is: Non-Linear | Time-Invariant | Memoryless | Causal | Stable (|sin|≤1)

Q7(a) — Properties of Discrete-Time LTI System
1. Linearity (Superposition)
If x₁[n]→y₁[n] and x₂[n]→y₂[n]: T{ax₁[n]+bx₂[n]} = a·y₁[n] + b·y₂[n] Example: y[n] = 2x[n] + x[n−1] (linear)
2. Time-Invariance
x[n−n₀] → y[n−n₀] for any integer n₀ Example: y[n] = x[n]cos(ω₀n) is NOT TI (cos changes with time)
3. Causality
y[n] = f(x[n], x[n−1], x[n−2],…) — no future values h[n] = 0 for n < 0 Example: y[n] = x[n] + x[n−1] (causal)
4. BIBO Stability
|x[n]| ≤ Mx < ∞ → |y[n]| ≤ My < ∞ Condition: Σ_{n=−∞}^{∞} |h[n]| < ∞ (absolutely summable) Example: h[n] = aⁿu[n], |a|<1 → stable; |a|≥1 → unstable
5. Convolution Properties
Commutative: x[n]∗h[n] = h[n]∗x[n] Associative: (x∗h₁)∗h₂ = x∗(h₁∗h₂) Distributive: x∗(h₁+h₂) = x∗h₁ + x∗h₂

Q9(a) — Time-Scaling Property of Discrete-Time Fourier Series (DTFS)
Statement

If x[n] is periodic with period N and DTFS coefficients {aₖ}, then the upsampled (time-expanded) signal:

y[n] = x_(M)[n] = { x[n/M], if n is a multiple of M { 0, otherwise has period MN with DTFS coefficients: bₖ = (1/M)·aₖ
Proof
DTFS of y[n] over period MN: bₖ = (1/MN) Σ_{n=0}^{MN−1} y[n]·e^(−j2πkn/MN) y[n] ≠ 0 only when n = qM (q = 0,1,…,N−1): bₖ = (1/MN) Σ_{q=0}^{N−1} x[q]·e^(−j2πk(qM)/MN) = (1/MN) Σ_{q=0}^{N−1} x[q]·e^(−j2πkq/N) = (1/M) · (1/N) Σ_{q=0}^{N−1} x[q]·e^(−j2πkq/N) = (1/M) · aₖ ╔════════════════╗ ║ bₖ = aₖ/M ║ ← proved ✓ ╚════════════════╝ Interpretation: Time expansion by M → frequency compression (more spectral replicas in [0, 2π], scaled by 1/M)

Q10 — Aliasing: Definition and Prevention
What is Aliasing?

Aliasing is the distortion caused when a signal is sampled below the Nyquist rate (fs < 2·fmax). High-frequency components fold over and appear as false low-frequency components — making reconstruction impossible.

Sampled spectrum: Xs(f) = fs · Σ_{n=−∞}^{∞} X(f − n·fs) If fs ≥ 2·fmax: spectral copies don't overlap → No aliasing If fs < 2·fmax: spectral copies overlap → ALIASING! Alias frequency: f_alias = |k·fs − f_signal| (nearest integer k) Example: f = 900 Hz, fs = 1000 Hz f_alias = |1×1000 − 900| = 100 Hz ← 900 Hz appears as 100 Hz!
Prevention Methods
  • ✅ Satisfy Nyquist: Ensure fs ≥ 2·fmax at all times
  • ✅ Anti-Aliasing Filter (AAF): Apply analog LPF with cutoff at fs/2 before sampling
  • ✅ Oversampling: Sample at much higher rate (e.g., 4×Nyquist), then digital filter + decimate
  • ✅ Band-pass sampling: Careful frequency placement using bandpass signals
