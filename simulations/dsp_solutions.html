Q3(a) Fourier Transform of x(t) = e−a|t|, a > 0 — with Frequency Spectrum

X(ω) = ∫₋∞^∞ e^(−a|t|)·e^(−jωt) dt Split integral at t=0: = ∫₋∞^0 e^(at)·e^(−jωt) dt + ∫₀^∞ e^(−at)·e^(−jωt) dt = ∫₋∞^0 e^((a−jω)t) dt + ∫₀^∞ e^(−(a+jω)t) dt = [e^((a−jω)t)/(a−jω)]₋∞^0 + [−e^(−(a+jω)t)/(a+jω)]₀^∞ = 1/(a−jω) + 1/(a+jω) = (a+jω + a−jω) / (a²+ω²) ∴ X(ω) = 2a/(a²+ω²) ← Real, even, Lorentzian spectrum

Q3(b) Convolution in Time ↔ Multiplication in Frequency (Proof)

Let y(t) = x(t) ∗ h(t) = ∫₋∞^∞ x(τ)·h(t−τ) dτ Take Fourier Transform: Y(ω) = ∫₋∞^∞ [∫₋∞^∞ x(τ)·h(t−τ) dτ] e^(−jωt) dt Interchange order of integration: Y(ω) = ∫₋∞^∞ x(τ) [∫₋∞^∞ h(t−τ)·e^(−jωt) dt] dτ Substitute u = t − τ → t = u+τ, dt = du: ∫₋∞^∞ h(u)·e^(−jω(u+τ)) du = e^(−jωτ)·H(ω) Therefore: Y(ω) = ∫₋∞^∞ x(τ)·e^(−jωτ)·H(ω) dτ = H(ω) · ∫₋∞^∞ x(τ)·e^(−jωτ) dτ = H(ω) · X(ω) ∴ x(t) ∗ h(t) ←FT→ X(ω)·H(ω) ✓ PROVED

Q4 Derive DTFT for Discrete-Time Aperiodic Sequence

Consider aperiodic x[n]. Create periodic x̃[n] with period N → ∞. DFS of x̃[n]: X̃[k] = Σ_{n=0}^{N−1} x̃[n]·e^(−j2πkn/N) As N→∞, let ω = 2πk/N (continuous variable): X̃[k] → X(e^jω) = Σ_{n=−∞}^{∞} x[n]·e^(−jωn) ← DTFT Inverse DTFT: x[n] = (1/2π) ∫₋π^π X(e^jω)·e^(jωn) dω Properties of DTFT: • X(e^jω) is periodic in ω with period 2π • Exists if x[n] is absolutely summable: Σ|x[n]| < ∞ (sufficient) • Frequency ω ∈ [−π, π] corresponds to normalized digital freq

Q5 Sampling Theorem + Nyquist Rate for x(t) = 1 + cos(2000πt) + sin(4000πt)

Nyquist-Shannon Sampling Theorem

A band-limited signal with maximum frequency fmax can be perfectly reconstructed from its samples if the sampling frequency satisfies:

f_s ≥ 2·f_max (Nyquist condition)

Analysis of Given Signal

x(t) = 1 + cos(2000πt) + sin(4000πt) Term 1: 1 → f₀ = 0 Hz (DC) Term 2: cos(2000πt) → 2πf = 2000π → f₁ = 1000 Hz Term 3: sin(4000πt) → 2πf = 4000π → f₂ = 2000 Hz f_max = 2000 Hz Nyquist Rate = 2 × f_max = 2 × 2000 = 4000 Hz
✅ Nyquist Rate = 4000 Hz. Sampling must be done at ≥ 4000 samples/second.

Q6 System Properties — y(t) = sin[x(t)]

Test 1: Time-Invariance

Apply delayed input x₁(t) = x(t−t₀): Response: y₁(t) = sin[x(t−t₀)] Delayed output: y(t−t₀) = sin[x(t−t₀)] → y₁(t) = y(t−t₀) ∴ TIME-INVARIANT ✓

Test 2: Linearity

Input: x(t) = ax₁(t) + bx₂(t) y(t) = sin[ax₁(t)+bx₂(t)] ≠ a·sin[x₁(t)] + b·sin[x₂(t)] (superposition fails) ∴ NON-LINEAR ✗

Test 3: Memoryless

y(t) depends only on x(t) at same instant t → MEMORYLESS ✓
📌 Conclusion: y(t) = sin[x(t)] is Time-Invariant, Memoryless, but Non-Linear.

Q7(a) Properties of Discrete-Time LTI Systems

1. Linearity

If x₁[n]→y₁[n] and x₂[n]→y₂[n], then ax₁[n]+bx₂[n] → ay₁[n]+by₂[n] (superposition holds)

2. Time-Invariance

x[n−n₀] → y[n−n₀] for any integer shift n₀. System parameters do not change with time.

3. Causality

y[n] depends only on x[n], x[n−1], x[n−2],… (no future inputs). h[n] = 0 for n < 0.

4. BIBO Stability

|x[n]| ≤ M < ∞ → |y[n]| ≤ B < ∞ Condition: Σ_{n=−∞}^{∞} |h[n]| < ∞

5. Commutative, Associative, Distributive Convolution

x[n]∗h[n] = h[n]∗x[n] (Commutative) (x∗h₁)∗h₂ = x∗(h₁∗h₂) (Associative) x∗(h₁+h₂) = x∗h₁ + x∗h₂ (Distributive)

Q10 Aliasing — Definition and Prevention

What is Aliasing?

Aliasing occurs when a signal is sampled below the Nyquist rate (fs < 2fmax). Spectral copies overlap, causing high-frequency components to appear as lower-frequency aliases — making perfect reconstruction impossible.

Mathematical Explanation

Sampled signal spectrum: X_s(f) = fs · Σ X(f − n·fs) If fs < 2·fmax → images overlap → ALIASING Alias frequency: f_alias = |f_signal − fs| Example: f_signal=1000 Hz, fs=800 Hz → f_alias=200 Hz

Prevention Methods

  • Increase sampling rate: Ensure fs ≥ 2fmax
  • Anti-aliasing (pre-filter): Apply LPF with cutoff at fs/2 before sampling
  • Oversampling + decimation: Sample at very high rate, digitally filter, then downsample
